# Profile

Homepage pribadi statis Adit, dibuat dengan HTML, CSS, dan JavaScript tanpa proses build.

## Jalankan secara lokal

Buka `index.html` di browser. Simpan `download.jpg` dan `profile-photo.jpeg` di folder yang sama. `download.jpg` digunakan sebagai tema latar, sedangkan `profile-photo.jpeg` adalah foto profil tetap.

## Deploy ke Vercel

1. Push repository ini ke GitHub.
2. Di Vercel, pilih **Add New → Project** lalu impor repository `remodit/Profile`.
3. Biarkan framework preset sebagai **Other** dan root directory sebagai `./`.
4. Deploy. Tidak perlu build command atau output directory.
